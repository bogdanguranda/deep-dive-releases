# Deep Dive Releases

This repository contains public release builds of the Deep Dive desktop app.
The source code is maintained in a private repository.

## Download
Go to the Releases page and download the installer for your OS.

## macOS (Unsigned Builds)
You will see a Gatekeeper warning because the app is unsigned.
Download the "-installer.zip" and run "Install Deep Dive.command" inside it.
It removes the quarantine flag and moves the app to /Applications.

## Windows (Unsigned Builds)
Windows may show a SmartScreen warning: "Windows protected your PC".
Click "More info" and then "Run anyway" to launch.

## Supported Platforms
- macOS
- Windows
